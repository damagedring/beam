    입력 ASN 배정

    새 작업 시작

    현재 시트의 입력은 그대로 두고, 새 작업 시트를 비어 있는 상태로 엽니다.

    파일에 보관하려면 먼저 작업파일을 저장하세요.

    도움말 · 예제

    ① 기준 데이터 입력 → ② 매장명 일부 입력 → ③ 상품 스캔 → ④ 결과 내보내기

    작업은 메모리 안에만 있습니다. 닫기 전 반드시 작업파일을 저장하세요. 저장한 JSON을 다시 열면 이어서 검수할 수 있습니다.

    바코드 앞의 0이 Excel에서 사라진 경우 복구할 수 없습니다. 원본 셀을 텍스트로 유지하세요.

    반품 예정 수량은 주문과 상품 바코드 기준으로 합산합니다. 정보 충돌은 확인 후 처리하세요. 검수 결과는 WMS에 자동 반영되지 않습니다.
